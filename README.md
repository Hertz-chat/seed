# 一颗种子 · A Seed 🌱

如果你从没用过 GitHub，也不会编程，欢迎从这里开始。

这个小小的公益项目，想邀请对技术和创造感兴趣的女生，在 GitHub 留下一份自己的表达。你可以写一个愿望、一个好奇的问题，或一句「我想试试看」。

你不需要先成为程序员，也不需要交出一份了不起的作品。

## 种下你的第一颗种子

全程使用电脑浏览器即可，不需要安装软件。

1. **Fork 这个仓库**：在自己的账号里得到一个副本。
2. **写一份 Markdown 宣言**：在副本的 `seeds/` 目录，新建以 GitHub 用户名命名的 `.md` 文件。
3. **提交 Pull Request（PR）**：邀请我们把你的宣言加入这个共同的花园。

👉 [跟着零基础教程一步步来](GUIDE.md) · [先看看示例](seeds/example.md)

提交 PR 后，你就完成了第一次协作邀请。宣言合并后，会出现在这里的 [seeds 目录](seeds/)。等待合并不影响这次尝试的意义。

## 不知道写什么？

可以从这些句子里任选一句，也可以完全用自己的方式写：

> 我希望自己能够……  
> 我一直想尝试……  
> 今天，我决定从这里开始。

只写「我想学会用 GitHub」也足够。随时可以通过新的 PR 更新自己的宣言。

## 希望这颗种子怎样生长？（可选）

到 [Issues](https://github.com/Hertz-chat/seed/issues/new/choose) 留下你的想法。比如你想尝试什么，或在哪一步需要帮助。写 Issue 不需要先完成宣言。

## 一点约定

- 尊重彼此的表达，不评价谁的愿望更值得。
- 只新增或修改自己的宣言，保留示例和其他人的文件。
- 这里是公开仓库。使用昵称即可，只写愿意公开的内容；不要填写手机号、住址或密码。提交历史也可能保留旧内容。
- 宣言由各自作者创作；参与不表示放弃署名或授权他人用于商业用途。

我们会查看 PR：只要是自己的表达、文件位置正确，并且尊重他人，就欢迎加入。格式不熟悉时，可以在 PR 里说一声，我们一起调整。

这是一个分享、探索和创造的小实验。没有参与人数目标，也不要求每颗种子都长成某种成果。

愿你发现：这里，也有你的位置。

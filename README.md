# 一颗种子 · A Seed 🌱

如果你从未用过GitHub，但对这个平台有好奇，欢迎从这里开始～

你不需要先成为程序员，也不需要交出一份多了不起的作品，只需要给自己10min，完成第一次勇敢的尝试！

## 种下你的第一颗种子

全程使用电脑浏览器即可，不需要安装软件。

1. **Fork 这个仓库**：在自己的账号里得到一个副本。
2. **修改一份 Markdown 文字**：参考示例，在副本的 `seeds/` 目录创建自己的 `.md` 文件，把文字改成你想说的话。
3. **提交 Pull Request（PR）**：把你的种子，放入我们共同的花园。

👉 [更详细的分步教程在这](GUIDE.md) 

## 不知道写什么？

## 花园告示牌
这是一个分享、探索和创造的小花园，不要求每颗种子都长成某种成果，希望游园快乐～🎉

- 尊重彼此真诚的表达，不评价、不攻击她人的文字。
- 只新增或修改自己的文件，不修改其他人的内容。
- 这里是公开仓库，使用昵称即可，只写愿意公开的内容；不要填写手机号、住址或密码，提交历史也可能保留旧内容。
